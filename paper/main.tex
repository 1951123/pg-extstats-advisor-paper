\begin{abstract}
Selecting extended statistics for a supplied workload is a physical-design
problem: the effect of one object depends on the other selected objects because
the estimator executes configuration-dependent control and state transitions.
Independent candidate scores therefore cannot reliably represent the design
space. We present CE-Replay, a workload-specialized, design-parametric,
executable representation of the supported statistics-sensitive estimator
transitions. It exposes two interfaces from the same transition system: an
objective oracle for hypothetical cardinality estimates and a semantic
dependency oracle for counterfactual move invalidation. The surrounding
pg-extstats-advisor keeps production PostgreSQL stock: a read-only production
capture seals a frozen realization, an offline advisor evaluates hypothetical
designs without production credentials, and the result is a recommendation for
DBA-controlled PostgreSQL deployment. Within PostgreSQL 16.14 conjunctive base-relation
restrictions, arity-two MCV and functional-dependency statistics, and the
supported predicate fragment, we validate native semantic fidelity, contextual
and non-monotone candidate behavior, exact incremental move evaluation, and
physical deployment and clean-room workflow closure. Independent DMV
realizations provide bounded robustness evidence rather than an invariance
claim. The result is a scoped physical-design system, not a general
PostgreSQL cardinality estimator, a global optimizer, or a latency guarantee.
\end{abstract}
