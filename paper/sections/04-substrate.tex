and precedence, and supported representable configurations without claiming

\subsection{Native planner hooks}
\textit{Planning note: explain how the PostgreSQL lookup path sees overlay
state while native code performs applicability, winner selection, clause

\subsection{Isolation and state lifetime}
\textit{Planning note: establish backend-local lifetime, no persistent
hypothetical deployment, and standard PostgreSQL DDL for final physical
deployment.}

\textit{Planning note: freeze PostgreSQL 16.14, one base relation, arity-two
MCV/FD statistics, fixed target, and the supported predicate fragment.}
